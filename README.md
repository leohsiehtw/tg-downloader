# TG 下載機器人

在 iPhone 分享連結（X、IG、YouTube、TikTok、Threads…）或轉傳壓縮檔給 Telegram 機器人，你的桌機就會下載影片或圖片，再貼到 KKSS 你選的子頻道。

```
iPhone 分享 ──► Telegram 機器人 ──► 桌機下載 ──► KKSS 的子頻道
```

桌機要開著才會處理。關機時傳的連結，開機後會自動補做。

## 平常怎麼用
1. 在任何 App 按「分享」→ **Telegram** → 選你的機器人 → 傳送。
2. 機器人跳出 Q / Ns / A / 頂 按鈕，按一下就會貼到那個子頻道。
3. 想省一步的話，分享時在留言欄打子頻道名稱（例如 `ns`），就直接貼過去。

處理時，私訊裡會有一則訊息每 3 秒更新進度：下載 %、轉檔 %、上傳 %、速度和大約還要多久。完成後這則會收掉，改成一則「✅ 已傳到…」，失敗會回「❌」和原因。

最多 3 個連結同時下載，上傳一次一個（照下載完的順序）；轉檔、壓縮也一次一支。想改同時下載的數量，在 `.env` 加 `DOWNLOAD_WORKERS=數字`。

## 壓縮檔（zip、7z、rar）
把壓縮檔轉傳給機器人（分卷的話所有分卷一起轉傳），它會下載、解壓，把裡面的**圖片當圖片、影片當影片**貼到子頻道，其他檔案不管。
- 一樣會跳子頻道按鈕；想省一步，轉傳時在留言欄打子頻道名稱（例如 `ns`）。
- 要密碼時，機器人會先自己試：檔名或說明裡的 `@帳號`、「密碼：xxx」，以及以前解開過的密碼。都不對就私訊問你「需要密碼」，你直接把密碼傳給它就會接著解；有好幾個在等時，長按那則「需要密碼」→ 回覆再傳。不想解了按「不解了，刪掉」。一天沒回會自動刪掉。
- 解開過的密碼存在 `.passwords.json`，下次先試。
- 大檔（像 600MB）會用你的帳號下載，所以 `.env` 要有 `UPLOAD_AS_USER=1`（你現在就是這樣設的）；沒開的話機器人只能收 20MB 以下的檔案。
- 解壓用 7-Zip，`configure.bat` 會自動安裝。
- 等密碼的壓縮檔重啟機器人後就不見了，要重新轉傳。

## 從手機操作
私訊機器人（或點輸入框旁的選單）：
- `/status`：一則每 3 秒更新、持續 5 分鐘的訊息，顯示電腦的 CPU、RAM、GPU、每顆硬碟的剩餘空間、網速，現在在做什麼、進度多少、還有幾個在排隊，以及處理了多少容量（這次啟動後、從開始用到現在的累計）。累計存在 `.totals.json`，想從頭算就把它刪掉。
- `/restart`：重新啟動機器人，順便更新下載工具，效果跟 `restart.bat` 一樣。如果還有工作在跑，會問你「做完再重啟」還是「現在重啟」。重開好了會回「✅ 機器人已重新啟動」；下載工具有更新的話，會在這則一起列出從哪版更新到哪版（開機時有更新也會私訊你）。

影片一律抓最高解析度。如果最高畫質是 iPhone 不能直接播的格式（VP9、AV1），會自動轉成同解析度的 H.264。圖片抓原圖，但 Telegram 顯示照片時會自己壓縮。

## 上傳資料夾
把電腦裡的照片或影片丟進 `E:\claude\tg-downloader\上傳`，機器人會私訊問你要貼到哪個子頻道，按一下就上傳。
- 一次丟多個檔案時，最多 10 個合成一組相簿。
- Telegram 確認整批都收到後，原檔才會丟進**資源回收筒**，需要時還能救回來。
- 只要有一個沒成功或檔案太大，整批都不刪，改移到 `上傳\失敗`，機器人會告訴你原因。

## 這個資料夾裡的檔案

**你會用到的**
| 檔案 | 什麼時候用 |
|---|---|
| `configure.bat` | 第一次設定，或要換 token、重新登入時 |
| 右下角的藍色圖示 | 綠點＝執行中、黃點＝重開中、紅點＝停住了（滑鼠移上去看原因）。右鍵可以看紀錄、重新啟動、結束 |
| `restart.bat` | 改完設定之後，讓背景的機器人重開（不在電腦前就私訊 `/restart`） |
| `stop.bat` | 想暫停機器人 |
| `start.bat` | 想看即時紀錄找問題時（先跑 stop.bat） |
| `上傳` 資料夾 | 丟進去的檔案會問你貼到哪，上傳完自動刪掉 |
| `bot.log` | 執行紀錄。機器人啟動、停止、當掉、上次關機的時間都會寫在這裡 |

**你自己的資料（不要傳給任何人）**
| 檔案 | 內容 |
|---|---|
| `.env` | 設定與 token，由 configure.bat 產生 |
| `.passwords.json` | 解開過的壓縮檔密碼 |
| `user.session` | 你 Telegram 帳號的登入狀態（傳大檔案用） |
| `cookies` 資料夾 | 網站的登入狀態（自己放，見下方） |

**程式本體（不用動）**：`bot.py`、`tray.pyw`（右下角圖示）、`user_upload.py`、`configure.py`、`requirements.txt`、`start-hidden.vbs`（開機自動執行用）、`ffmpeg-gpu` 資料夾（用顯卡壓縮影片的 ffmpeg 8.0，因為新版不支援 GTX 10 系列的驅動）

## 開機自動執行
已經設好了。「啟動」資料夾裡有一個指向 `start-hidden.vbs` 的捷徑，開機後右下角會出現圖示，機器人在背景執行，當掉 10 秒後也會自動重開。

機器人停止或當掉時，會私訊你一則 Telegram 通知，附上最後幾行紀錄。電腦關機或睡眠造成的停止，會在下次啟動時告訴你大概幾點停的。要取消的話，按 `Win + R` 輸入 `shell:startup`，刪掉 `tg-downloader` 捷徑。

## 常見問題
- **X / IG 抓不到**：這類網站常要登入。在 Brave 登入該網站，用擴充功能「Get cookies.txt LOCALLY」按 Export，存進這個資料夾裡的 `cookies` 資料夾。每個網站各存一個檔，檔名隨意（用擴充功能預設的就好），機器人會依網址自己挑。下次下載就會用到，不用重啟。抓不到時重新匯出一次蓋掉舊檔，cookies 會過期。建議用小帳號。
- **大檔案**：用你自己的帳號上傳，最大 2GB，所以貼文會顯示是你發的。超過 2000MB 的影片會自動壓縮畫質，壓到接近 2000MB 再上傳（有 NVIDIA 顯卡就用顯卡壓，比較快），一樣是 H.264 影片，點開就能播。要改回由機器人發文（上限 50MB），在 `.env` 設 `UPLOAD_AS_USER=0`。
- **某個網站突然壞了**：執行 `restart.bat` 或私訊 `/restart`，會順便更新下載工具，通常就修好了。
- **機器人沒反應**：看 `bot.log` 最後幾行。出現「token 不對」就重新執行 `configure.bat`。
- **新增子頻道**：到那個子頻道打 `/topicid`，把機器人回的 `名稱:id` 加到 `.env` 的 `TOPICS=` 後面（用逗號分隔），再執行 `restart.bat`。
